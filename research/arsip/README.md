# Arsip

File lama yang disimpan untuk referensi, tetapi tidak dipakai kode mana pun.

| Path | Isi | Asal |
|---|---|---|
| `catatan_docs/` | Catatan awal pembuatan Zul: tutorial boilerplate CLI, perbandingan library, `[build-system]`, daftar perintah, dan draf arsitektur hexagonal. | `docs/` |
| `catatan_docs/README-lama.md` | README repository sebelum dipisah per kategori, berisi diagram arsitektur dan alur. | `README.md` |
| `runs/` | Hasil training YOLO dari `framework/notebooks/training_yolo.ipynb`. | `runs/` |
| `assets/` | Contoh config Milvus dan Redis versi awal, logo, dan catatan filosofi logo. | `assets/` |
| `books/` | Buku PDF. Hanya ada di laptop, tidak ikut git. | `assets/books/` |
| `main.py`, `note_idea`, `organize_assets.py` | Script awal dan catatan ide. | root |

`organize_assets.py` memindahkan isi `tutorial/assets`, folder yang sudah tidak ada. Script itu disimpan sebagai catatan, bukan untuk dijalankan lagi.
