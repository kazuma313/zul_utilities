# Pengembangan diri

Tempat belajar dan mencoba: latihan coding yang dikerjakan manual, proyek mandiri, dan arsip. Isinya bukan bagian dari paket `zul`, tidak ikut diperiksa black dan ruff, dan tidak ikut diuji oleh `uv run pytest`.

| Folder | Isi |
|---|---|
| [`latihan/`](latihan/) | Soal latihan dengan test-nya: algoritma sorting dan string, simulasi peluang, pengolahan citra, benchmark. |
| [`proyek/`](proyek/) | Proyek mandiri dengan dependency dan README sendiri. |
| [`arsip/`](arsip/) | Catatan lama, hasil training, dan file yang tidak dipakai lagi. |
| `computer_vision/` | Proyek CCTV toko sepatu. Ada di laptop saja, tidak ikut git karena berisi video dan bobot model. Versi boilerplate-nya ada di [`framework/project/computer_vision/`](../framework/project/computer_vision/). |

Semua perintah dijalankan dari root repository, karena `.venv` ada di sana.
