2. Never use the same layout twice in a row. Include at least one of stat_callout, quote, icon_grid.
3. chart_type is one of bar, line, pie, doughnut, area. "values" are numbers; "labels" and "values" have the same length.
4. Only use image layouts when the user gives an image file name. Only use numbers and facts given by the user.
5. Plain text only: no **bold**, no bullet characters, no emojis, no line breaks inside a string.
6. Keep text short: titles under 8 words, bullets under 12 words, card body under 12 words, stat value under 8 characters.
