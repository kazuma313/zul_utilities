Pandas dan DataFrame

Ditulis oleh qwen3:8b dari pengetahuan umum; periksa angka penting ke sumber resmi

Apa

Pandas adalah library Python untuk mengolah data. DataFrame adalah struktur data seperti tabel yang menyimpan data dalam baris dan kolom.

pandasLibrary Python untuk mengolah data dalam bentuk tabel.
DataFrameStruktur data seperti tabel yang menyimpan data dalam baris dan kolom.
kolomBagian dalam tabel yang menyimpan data sejenis, seperti 'harga' atau 'jumlah'.

Bagaimana

Pertama, import pandas. Lalu, gunakan read_csv untuk membaca file CSV. Masukkan nama file, lalu simpan hasilnya ke variabel. Akhirnya, tampilkan data menggunakan head() atau info().

Mengapa penting

Dengan mengetahui struktur data, kita bisa memahami apa yang perlu dianalisis. Tapi, data mungkin masih ada nilai yang tidak sesuai, yang akan dibahas di modul berikutnya.

Melihat isi data

Ditulis oleh qwen3:8b dari pengetahuan umum; periksa angka penting ke sumber resmi

Apa

Menampilkan baris pertama dan ringkasan data membantu memahami apa yang ada dalam file CSV. Ini adalah langkah awal sebelum memproses data lebih lanjut.

read_csvFungsi pandas untuk membaca file CSV dan mengubahnya menjadi DataFrame.

Bagaimana

Gunakan head() untuk melihat baris pertama. Gunakan info() untuk melihat jumlah baris dan tipe data setiap kolom. Ini membantu memahami struktur data sebelum memprosesnya.

Mengapa penting

Melihat ringkasan data membantu memahami jenis data yang ada. Tapi, data mungkin masih ada nilai yang tidak sesuai, yang akan dibahas di modul berikutnya.
