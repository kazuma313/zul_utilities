Silabus belajar

Belajar Python untuk Analisis Data dari Nol

Dalam modul ini, Anda akan mempelajari dasar-dasar Python yang relevan untuk analisis data. Anda akan belajar cara membaca data, melakukan perhitungan sederhana, dan memvisualisasikan hasil analisis. Setelah menyelesaikan modul ini, Anda akan mampu menganalisis data penjualan sederhana tanpa perlu menggunakan rumus manual.

  • Pemula
  • 6 modul
  • ± 14 jam total
  • 4 minggu, 4 jam per minggu
Setelah selesai, Anda bisa:
  • Menulis program Python sederhana untuk membaca file CSV.
  • Melakukan perhitungan dasar pada data menggunakan Python.
  • Memvisualisasikan data dengan grafik sederhana.
  • Membersihkan dan memformat data untuk analisis.
  • Mengidentifikasi potensi masalah dalam dataset.
Silabus ini dibuat dengan asumsi: Anda memiliki pengetahuan dasar tentang komputer dan internet. Anda bersedia meluangkan waktu sekitar 4 jam per minggu untuk belajar. Anda ingin mengembangkan kemampuan analisis data secara mandiri. Kalau ada yang tidak cocok, minta disesuaikan.
Cara memakai: kerjakan modul berurutan, karena setiap modul memakai istilah dari modul sebelumnya. Di setiap modul: baca materi, kerjakan latihan, lalu jawab kuis. Centang Selesai kalau kuisnya sudah benar semua.
Contoh yang dipakai di semua modul: Budi adalah pemilik toko online yang ingin menganalisis data penjualan bulanan. Anda akan membantu Budi dengan menggunakan Python untuk melihat tren penjualan, produk terlaris, dan lain-lain.
